# Assessed Papers Ledger

One row per research paper that has been read for what it could improve in the pipeline, including the papers that yielded nothing. The [`paper-assessment`](../../skills/paper-assessment/SKILL.md) skill reads this file first, so that a paper is not assessed twice and a closed dead end is not proposed again, and adds a row per paper when it finishes.

- **Verdict** is the outcome at the time of the assessment:
  - `yields`: at least one tier was planned from it;
  - `decision`: its only output is a decision left to the user;
  - `watch`: nothing to build, but a named event would change that;
  - `nothing`: no mechanism transfers;
  - `triaged`: read in triage mode only, with at least one mechanism that may transfer. No plan exists and nothing was mapped or challenged, so the next full assessment replaces the row.
- **The current state of a tier is not kept here.** It is in the plan and in [`./backlog.md`](./backlog.md).
- PDFs are in the gitignored `docs/papers/` folder, so papers are cited by file name or arXiv id and never linked.
