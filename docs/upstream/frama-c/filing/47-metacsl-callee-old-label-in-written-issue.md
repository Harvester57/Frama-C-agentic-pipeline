# [MetAcsl] The `\written` / `\read` instances at a call keep the `Old` / `Pre` labels of the callee's contract

<!-- Everything below this line is the issue description. Tracker: pub/meta (MetAcsl), not pub/frama-c. -->

### Summary

At a call to a function known by its contract (here an undefined function, with the default
`-meta-check-ext`), a `\writing` property is instantiated with `\written` set to each assigns
location of the callee, its formals replaced by the actual arguments. The labels of the callee's
contract are kept, and the instance is an assertion of the caller:

- `Old`, from `\old(...)` in the assigns clause or given by the kernel to a labelled logic
  function called there without a label (`len(p)` is typed `len{Old}(p)`, the same happens to
  `strlen(s)`), is not allowed in a statement annotation. `-check` reports `Logic label Old is
  not declared in this scope`, the printed code does not re-parse, WP stops with `Unexpected
  error (Wp__NormAtLabels.LabelError(_))`, and E-ACSL aborts with `invalid label 'Old' within
  statement annotation 'Assertion'`.
- `Pre` is accepted in the callee's contract (where it is its pre-state) and is allowed in a
  statement annotation, but there it is the pre-state of the caller, not the state before the
  call. The instance checks another location, and WP proves a false property.

The same happens to `\read` with a `\reading` property (the `\from` part of the assigns clause)
and to the assumes clauses added as hypotheses (see the end).

### Steps to reproduce the issue

`callee_labels.c`:

```c
char out[8];
int secret;
int n;

/*@ logic integer len{L}(int *p) = \at(*p, L); */

#if defined(USE_OLD)
/*@ assigns d[0 .. \old(*p)]; */
#elif defined(USE_PRE)
/*@ assigns d[0 .. \at(*p, Pre)]; */
#else
/*@ assigns d[0 .. len(p)]; */ /* typed as len{Old}(p) */
#endif
void fill(char *d, int *p);

/*@ assigns n; ensures n == 7; */
void set7(void) { n = 7; } /* not a target: no instance here */

/*@ requires n == 2; */
void caller(void)
{
  set7();
  fill(out, &n); /* writes out[0 .. 7] */
}

int main(void)
{
  n = 2;
  caller();
  return 0;
}

/*@ meta \prop, \name(no_write_secret), \targets({caller}), \context(\writing),
      \separated(\written, &secret);
*/

/*@ meta \prop, \name(stays_in_prefix), \targets({caller}), \context(\writing),
      \subset(\written, out + (0 .. 3));
*/
```

```
$ frama-c callee_labels.c -meta -then-last -print -ocode out.c
$ frama-c out.c
$ frama-c -check callee_labels.c -meta -then-last -print
$ frama-c callee_labels.c -meta -then-last -wp
$ frama-c callee_labels.c -meta -then-last -e-acsl
$ frama-c -cpp-extra-args=-DUSE_OLD callee_labels.c -meta -then-last -e-acsl
$ frama-c -cpp-extra-args=-DUSE_PRE callee_labels.c -meta -then-last -print -wp
```

### Expected behaviour

The callee's `Old` and `Pre` denote its pre-state, which is the state just before the call. The
instance placed before the call should read `n` there:

```
  /*@ assert
        stays_in_prefix: meta:
          \subset(&(out[0]) + (0 .. len(&n)), &out[0 .. 3]);
  */
  fill(out,& n);
```

(with `\at(*(&n),Here)` for the other two variants). The printed code should re-parse, WP and
E-ACSL should run, and WP should not prove `stays_in_prefix`, which is false: `n` is 7 at the
call, so `fill` writes `out[0 .. 7]`.

### Actual behaviour

The instance keeps `len{Old}`:

  /*@ assert

        stays_in_prefix: meta:
          \subset(&(out[0]) + (0 .. len{Old}(&n)), &out[0 .. 3]);

### Additional information (optional)

- **Where we met it.** A contract `assigns __dest[0 .. strlen(__src)] \from __src[0 ..
  strlen(__src)];` for `strcpy`, used so that a `\writing` property is checked at its calls in an
  E-ACSL build. With a user function `void copy(char *d, const char *s)` and the same clause, the
  instance at `copy(buf,"abc")` is `\separated(&(buf[0]) + (0 .. strlen{Old}(&("abc"[0]))),
  &secret)` and E-ACSL aborts with `invalid label 'Old' within statement annotation 'Assertion'
  in '&("abc"[0])'`.
- **The same with the other modes.** With `-meta-fold` the label ends up in the argument of the
  folded predicate, with `-meta-quantify-range` in the quantifier bound, and with a property that
  uses `After` (the assertion is then placed after the call) it stays `Old`.
- **`\read` and assumes clauses.** `t5.c` holds the declarations of `secret`, `n` and `len` of
  `callee_labels.c`, and:

  ```c
  /*@ behavior big:
        assumes \at(*p, Pre) > 2;
        assigns d[0] \from s[0 .. len(p)];
      behavior small:
        assumes *p <= 2;
        assigns d[0] \from s[0 .. \old(*p)];
  */
  void copy(char *d, const char *s, int *p);

  void caller(char *d, const char *s)
  {
    copy(d, s, &n);
  }

  /*@ meta \prop, \name(no_read_secret), \targets({caller}), \context(\reading),
        \separated(\read, &secret);
  */

  /*@ meta \prop, \name(no_write_secret), \targets({caller}), \context(\writing),
        \separated(\written, &secret);
  */
  ```

  `frama-c t5.c -meta -then-last -print` gives:

  ```
  void caller(char *d, char const *s)
  {
    /*@ assert
          no_write_secret: meta:
            \at(*(&n),Pre) > 2 ⇒ \separated(d + 0, &secret);
    */
    /*@ assert no_write_secret: meta: *(&n) ≤ 2 ⇒ \separated(d + 0, &secret);
    */
    /*@ assert
          no_read_secret: meta:
            \at(*(&n),Pre) > 2 ⇒ \separated(s + (0 .. len{Old}(&n)), &secret);
    */
    /*@ assert
          no_read_secret: meta:
            *(&n) ≤ 2 ⇒ \separated(s + (0 .. \old(*(&n))), &secret);
    */
    copy(d,s,& n);
    return;
  }
  ```

- **Where it comes from, as far as I can tell.** The visitor in `inspect_contract`
  (`meta_annotate.ml`) replaces the lvalues rooted at a formal by the actual arguments, and does
  not look at labels. The assumes clauses of the behavior, added as hypotheses, go through the
  same visitor.
- **A possible change.** MetAcsl's own `Before` label already means "the state before the
  instrumented statement": `replace_after_before` turns it into `Here` when the assertion precedes
  the call, and into a label on the call when it follows it. Mapping `BuiltinLabel (Old | Pre)` to
  `FormalLabel "Before"` in that visitor gives the expected output above for the three variants,
  in the default, `-meta-fold` and `-meta-quantify-range` modes, and with an `After` property
  (`len{meta_pre_0}(&n)`, with `meta_pre_0` on the call). In the `\read` example, every
  `Pre` and `Old` of the four assertions becomes `Here` (`\at(*(&n),Here)`, `len(&n)`), and WP
  proves the six goals. I will send it as a merge request with a test.
- **Not covered by that change:** `Post` in an assigns clause (a location that depends on the
  callee's post-state cannot be checked before the call), and an unlabelled read such as `*p` in
  the location when the assertion is placed after the call.
