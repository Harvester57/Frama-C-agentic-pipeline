# [Libc] `<wchar.h>` alone cannot locate `__fc_stdout` / `__fc_stdin` for `wprintf` and `wscanf`

<!-- Everything below this line is the issue description. -->

### Summary

ISO C11 7.29.2.10 and 7.29.2.11 declare `wprintf` and `wscanf` in `<wchar.h>` without requiring
`<stdio.h>`. Frama-C's Variadic translation classifies both functions as `StdIO` and looks up the
internal libc globals `__fc_stdout` and `__fc_stdin`, which are currently declared only in
`share/libc/stdio.h`. Including `<wchar.h>` without `<stdio.h>` therefore emits
`Unable to locate global __fc_stdout` / `__fc_stdin` warnings and drops the stream `assigns` and
`\from` clauses on `__fc_stdout->__fc_FILE_data` and `__fc_stdin->__fc_FILE_data`.

### Steps to reproduce the issue

`repro.c`:

```c
#include <wchar.h>

int main(void) {
  int x = 0;
  wprintf(L"%d\n", x);
  wscanf(L"%d", &x);
  return x;
}
```

```sh
frama-c repro.c -print
```

### Expected behaviour

No `Unable to locate global` warnings are emitted, `wprintf_va_1` assigns
`__fc_stdout->__fc_FILE_data`, and `wscanf_va_1` assigns `__fc_stdin->__fc_FILE_data` and derives
`*param0` from `__fc_stdin->__fc_FILE_data` (without exposing the `stdin`/`stdout`/`stderr` macros
in `<wchar.h>`, per ISO C11 7.29).

### Additional information (optional)

**Cause.** `src/kernel/services/ast_transformations/variadic/classify.ml:142,145` classifies
`wprintf` and `wscanf` as `StdIO`, and `standard.ml:398-406, 588-598` calls
`find_global env "__fc_stdout"` and `find_global env "__fc_stdin"`. Both globals are declared only
in `share/libc/stdio.h:52-59`, whereas `share/libc/wchar.h:20` includes `share/libc/__fc_define_file.h`
(which defines `FILE` without declaring `__fc_stdin` / `__fc_stdout`). All other Variadic-classified
headers (`fcntl.h`, `unistd.h`, `sys/ioctl.h`, `stropts.h`, `stdio.h`, and `swprintf`/`swscanf`/
`fwprintf`/`fwscanf` in `wchar.h`) already have their required symbols in scope. Note that
`share/libc/wchar.h:587,623,655,661` (`getwchar`, `putwchar`, `vwprintf`, `vwscanf`) also carry
`//missing: assigns ... *__fc_stdin / *__fc_stdout` comments.

**Fix.** Move the three internal extern declarations (`__fc_stderr`, `__fc_stdin`, `__fc_stdout`,
which are in the implementation-reserved double-underscore namespace under ISO C11 7.1.3) into
`share/libc/__fc_define_file.h` (included only by `stdio.h` and `wchar.h`), while keeping the
`#define stderr/stdin/stdout` macros exclusively in `share/libc/stdio.h`. A merge request with a
regression test follows.
