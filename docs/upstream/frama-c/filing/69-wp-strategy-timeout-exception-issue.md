# [WP] `strategy` timeout with a suffix or integer overflow aborts with an internal error (`Failure("int_of_string"|"float_of_string")`)

<!-- Everything below this line is the issue description. -->

### Summary

In `plugins/wp/src/ProofStrategy.ml`, `parse_provers` wraps `int_of_string` and `float_of_string` in `with Invalid_argument _` to report `"Invalid timeout"`. Because OCaml's `int_of_string` and `float_of_string` raise `Failure _`, the handler is unreachable: any `strategy` timeout with an integer suffix (`2u`, `2L`), a float suffix (`2.5f`, `2.5d`), or an overflowing integer (`99999999999999999999`) aborts Frama-C with an internal error (exit code 4) instead of a clean `"Invalid timeout"` annotation error.

### Steps to reproduce the issue

`strat_int.i`:

```c
/*@ lemma dummy: \forall integer i; i < 0 ==> i < 1; */
/*@
  strategy S: \prover("Alt-Ergo", 2u);
  proof S: dummy;
*/
```

`strat_float.i`:

```c
/*@ lemma dummy: \forall integer i; i < 0 ==> i < 1; */
/*@
  strategy S: \prover("Alt-Ergo", 2.5f);
  proof S: dummy;
*/
```

`strat_ovf.i`:

```c
/*@ lemma dummy: \forall integer i; i < 0 ==> i < 1; */
/*@
  strategy S: \prover("Alt-Ergo", 99999999999999999999);
  proof S: dummy;
*/
```

```sh
OCAMLRUNPARAM=b frama-c -debug 1 -wp -wp-timeout 5 strat_int.i
frama-c -wp -wp-timeout 5 strat_float.i
frama-c -wp -wp-timeout 5 strat_ovf.i
```

### Expected behaviour

All three files should be rejected cleanly with the intended user/annotation error (`Invalid timeout`) and exit code 1, without an internal error or crash prompt.

### Actual behaviour

`strat_int.i` (and identically `strat_ovf.i`), exit code 4:

```text
[kernel] Parsing strat_int.i (no preprocessing)
[kernel] Failure: Typechecking ACSL extension strategy raised exception Failure("int_of_string")
[kernel] Frama-C aborted: internal error (Typechecking ACSL extension strategy raised exception Failure("int_of_string")).
```

`strat_float.i`, exit code 4:

```text
[kernel] Parsing strat_float.i (no preprocessing)
[kernel] Failure: Typechecking ACSL extension strategy raised exception Failure("float_of_string")
[kernel] Frama-C aborted: internal error (Typechecking ACSL extension strategy raised exception Failure("float_of_string")).
```

### Additional information (optional)

**Cause.** `plugins/wp/src/ProofStrategy.ml`, `parse_provers`, lines 158-169 (commit `189053d4a2`):

```ocaml
    | PLconstant (IntConstant t) ->
      let time = try int_of_string t with Invalid_argument _ ->
        error ctxt loc "Invalid timeout" in
...
    | PLconstant (FloatConstant t) ->
      let time = try float_of_string t with Invalid_argument _ ->
        error ctxt loc "Invalid timeout" in
      if time < 0.0 then error ctxt loc "Invalid timeout" ;
```

Both `int_of_string` and `float_of_string` raise `Failure _`, never `Invalid_argument _`.

**Fix.** Catch `Failure _` in both branches and reject non-finite floats (`not (Float.is_finite time) || time < 0.0`). A merge request follows.
